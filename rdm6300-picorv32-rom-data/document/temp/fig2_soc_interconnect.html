Kiến Trúc Bus soc_interconnect.v & Cơ Chế Thực Thi Bare-Metal C

Giải mã không gian địa chỉ, điều phối bộ nhớ Flash XIP / 1KB SRAM và cầu nối ngoại vi MMIO cho CPU PicoRV32

CPU Master: PicoRV32 RV32IMC
Nhân RISC-V 32-bit thực thi trực tiếp
• PROGADDR_RESET: 0x0025_0000 (Flash XIP)
• Stack Pointer (sp): 0x0000_0400 (Đỉnh SRAM)
Tín hiệu Bus Native PicoRV32:
> cpu_mem_valid: Kích hoạt chu kỳ bus (1 bit)
> cpu_mem_addr[31:0]: Địa chỉ bộ nhớ truy cập
> cpu_mem_wdata[31:0]: Dữ liệu ghi ra từ CPU
> cpu_mem_wstrb[3:0]: Mặt nạ ghi từng byte
< cpu_mem_rdata[31:0]: Dữ liệu đọc trả về CPU
< cpu_mem_ready: Tín hiệu báo hoàn tất chu kỳ
CPU tự động dừng (stall) cho đến khi ngoại vi hoặc bộ nhớ kéo cpu_mem_ready = 1.
soc_interconnect.v Central Bus
Bộ giải mã địa chỉ & Ghép kênh tín hiệu trả về
1. Logic giải mã địa chỉ (Range & Prefix Decoding):
sel_sram = cpu_mem_valid && (addr < 32'h0000_0400);
sel_spimem = cpu_mem_valid && (addr >= 0x0010_0000 && addr < 0x0100_0000);
sel_spicfg = cpu_mem_valid && (addr == 32'h0200_0000);
sel_rfid = cpu_mem_valid && (addr[31:28] == 4'h1);
sel_uart = cpu_mem_valid && (addr[31:28] == 4'h3);
sel_gpio = cpu_mem_valid && (addr[31:28] == 4'h4);
2. Bộ ghép kênh dữ liệu đọc (cpu_mem_rdata Mux):
cpu_mem_rdata = sel_sram ? sram_rdata :
               sel_spimem ? spimem_rdata :
               sel_spicfg ? spimem_cfg_do :
               sel_rfid ? rfid_rdata :
               sel_uart ? uart_rdata :
               sel_gpio ? gpio_rdata : 32'd0;
3. Bộ tổng hợp tín hiệu sẵn sàng (cpu_mem_ready OR):
cpu_mem_ready = sram_ready | spimem_ready | sel_spicfg | rfid_ready | uart_ready | gpio_ready;
Slave 0: 1KB Data SRAM (data_sram.v) 1 Cycle Latency
Dải địa chỉ: 0x0000_0000 - 0x0000_03FF
• Chứa Stack frames C, biến cục bộ, mảng dữ liệu tạm thời, .bss, .data.
• Tốc độ 1 chu kỳ xung nhịp (sram_ready = 1), chạy buffer flashio_worker.
Slave 1 & 1b: SPI Flash XIP & Config (spimemio.v) XIP SPI Bus
Dải địa chỉ: 0x0010_0000 - 0x00FF_FFFF & 0x0200_0000 (CFG)
• XIP Firmware (.text): Bắt đầu tại 0x0025_0000 (Vector Reset Boot).
• Whitelist DB: Sector 48 (0x0030_0000, 64KB, tối đa 4096 thẻ).
• Access Logs: Sector 49 (0x0031_0000, 64KB, 512 bản ghi vào ra).
• SPICFG (0x0200_0000): Thanh ghi cấu hình bitbang ghi/xóa Flash từ SRAM.
Slave 2: RDM6300 RFID UART Peripheral FIFO 32B
Địa chỉ: 0x1000_0000 (DIV) | 0x1000_0004 (DAT)
Baud divider = 5208 (9600 baud @ 50MHz). Đọc DAT lấy byte từ RX FIFO. Trả về 0xFFFFFFFF nếu rỗng.
Slave 3: Host PC UART Peripheral Dual FIFO 32B
Địa chỉ: 0x3000_0000 (DIV) | 0x3000_0004 (DAT)
Giao tiếp 2 chiều với PC Terminal. Ghi DAT nạp vào TX FIFO, đọc DAT lấy byte từ RX FIFO.
Slave 4: GPIO Status LEDs MMIO Output
Địa chỉ: 0x4000_0000 (REG_GPIO_LEDS)
Bit 0: Alive Heartbeat | Bit 1: Access Denied / Warn | Bit 2: Access Granted | Bit 3: Flash Active.

① Boot XIP Trực Tiếp từ Flash
Khi reset nhả về 0, CPU PicoRV32 nhảy tới vector 0x0025_0000. Bộ giải mã soc_interconnect kích hoạt sel_spimem.
Bộ điều khiển spimemio tự động phát lệnh đọc 0x03, kéo từng từ lệnh 32-bit từ Flash vào CPU mà không cần nạp vào RAM trước.
② Khởi Tạo Stack C trên 1KB SRAM
File khởi động start.s gán con trỏ sp = 0x0000_0400 (đỉnh SRAM nội).
Khi code C gọi hàm hoặc cấp phát biến cục bộ, CPU truy xuất vùng < 0x0400. soc_interconnect kích hoạt sel_sram phản hồi tức thì trong 1 chu kỳ (sram_ready = 1), tránh nghẽn bus SPI.
③ Điều Khiển Ngoại Vi Bằng MMIO
Firmware C thao tác với ngoại vi qua con trỏ volatile trong file soc_regs.h.
Khi C đọc REG_RFID_UART_DAT, CPU truy cập địa chỉ 0x1000_0004. Interconnect giải mã tiền tố 0x1 bật sel_rfid, lấy byte từ FIFO 32B nhanh chóng mà không làm mất frame thẻ.
④ Chạy Mã RAM Ghi Flash An Toàn
Bộ nhớ SPI Flash không thể vừa đọc lệnh XIP vừa ghi xóa Sector. Khi cần ghi thẻ mới hoặc lưu log, hàm flashio copy đoạn mã nhỏ flashio_worker lên Stack SRAM.
CPU nhảy lên SRAM thực thi, truy cập 0x0200_0000 (sel_spicfg) điều khiển SPI bit-bang an toàn 100%.
